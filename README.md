# S.I.R Ambrose Concepts — Front-end website

This is a self-contained, front-end-only website for S.I.R Ambrose Concepts. The logo is embedded in `index.html`, so no separate image asset is required.

## Preview locally
Open `index.html` in a modern web browser.

## Deploy to Render
1. Push the contents of this folder to a GitHub repository.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Set **Build Command** to blank (or `echo static site`).
4. Set **Publish Directory** to `.`.
5. Deploy.
